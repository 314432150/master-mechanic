## 模板

新建 ADR 时复制以下结构（按标题层级书写，不要修改字段名）：

- 标题：`# ADR-XXX：<标题>`
- 表格：日期（YYYY-MM-DD）、状态（提议 / 接受 / 废弃）、关联需求（FR-XX / §X.X）
- `## 背景`：什么问题必须现在决策
- `## 决策`：选了什么
- `## 备选方案`：各方案与放弃理由
- `## 后果`：代价、引入的约束、后续影响；若某方案触及七条红线，必须写明为何弃用

## 写作要求

1. 决策必须能追溯到需求条款或红线编号；
2. 「后果」不得为空；没有代价的决策说明没想清楚；
3. 状态变为"接受"后，同步更新 `../architecture.md` 开放决策表与 `../progress.md`。
