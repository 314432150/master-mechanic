## set-20260912-01 — 启动页标定样本（T1-5c）

| 项 | 内容 |
| --- | --- |
| 采集设备 | vivo V2463A / Android 16（API 36） |
| 采集日期 | 2026-09-12 |
| 场景 | 《王者荣耀》启动页（「开始游戏」按钮、区服信息、「退出」等） |
| 数量 | 48 帧（每秒 1 帧，仅目标前台时录制） |
| 帧画布 | 1440×3168（竖持授权会话；横屏游戏内容居中带嵌入，见代表帧） |
| 命名 | frame-<补零毫秒数>.png（字典序 = 时间序） |
| 用途 | T1-5c 标定输入：框选「开始游戏」→ 模板 launch_start（131×37，1/3 降采样） |
| 样本位置 | 采集设备应用私有目录（files/calibration/frames/）；本仓存代表帧 |
| 代表帧 | [t1-5-launch-start-frame.png](samples/t1-5-launch-start-frame.png)（frame-0002892990467） |

备注：帧画布方向随授权时持机姿态变化（本集为竖持会话）；标定帧与运行帧需同姿态采集，
否则帧尺寸不一致（运行期有告警、识别不可用）。真实标志框选在小目标场景下需先放大画面
（T1-5d 交互），选区以比例坐标记录、与画布尺寸解耦。
