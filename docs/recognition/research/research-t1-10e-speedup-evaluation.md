## 1. 方法与口径

- 数据：固定批次 `set-20260912-03` 中**非纯空帧** 51 帧（`neg-plain` 53 帧画面近恒定、分数恒为 0，
  不参与统计），信号 `launch_start`（模板 131×37，calib-v1）。
- 探针：参数化**复刻**匹配器（采样步长 / 网格步长 / 精搜锚点数 / 剪枝开关），生产实现保持不变。
- 自校验：复刻基线（采样 2 / 网格 2 / K64 / 不剪枝）与生产 `TemplateMatcher.findPeaks`
  **逐字段一致（不一致 0 帧）**——证明探针与生产口径一致。
- 耗时：每帧每变体跑 5 轮取**中位**（JVM 相对比值，非设备绝对值；绝对值受 JIT / 调度影响）。
- 一致性：按**判定口径**比对——判定结论（命中 / 未命中 / 不可信）、best 位置与分数、competitor 分数
  （判定只取前两个峰值，见 `SignalDetector.judge`）。
- 剪枝：上界剪枝（Cauchy–Schwarz）。剩余行点积
  `Σ t'·p = p̄_rem·Σ_rem t' + Σ t'·(p − p̄_rem)`，后一项上界 `√(Σ_rem t'² · Σ_rem(p − p̄_rem)²)`，
  两项均由前缀和 O(1) 取得；上界分数低于当前最优即剪掉。

  > 首版实现漏掉**均值修正项**（`Σt' = 0` 只对整模板成立，剩余行子集不成立），实测误剪导致
  > 9/51 帧判定结论改变、best 分数最大差 0.454——修正后该现象消失。此教训一并记录。

## 3. 逐手段解读

### 3×3 采样粗搜（更稀疏的采样模板，采样点约 1/3）

- 提速 ×1.39（桌面），**判定结论 0 帧改变**，但 **7/51 帧 best 位置不一致**（约 14%）。
- 机理：更稀疏采样让粗搜打分分辨率下降，个别帧的最强网格点落到真峰邻域之外 → 精搜邻域选错 →
  最终峰值偏移数像素。分数差异极小（最大 0.0011），不影响命中判定，但**不满足 T1-10a 确立的
  「判定记录逐字段一致」口径**（位置字段变化）。
- 组合剪枝后可到 ×1.70，漂移不变（仍 7 帧）。

### 部分和剪枝（上界剪枝）

- **语义零漂移**：结论 0 帧变化、best 位置 0 帧变化、best 分数差 0（竞争分最大差 0.004 源于低分候选被剪，
  不影响判定）。
- 但提速仅 **×1.06**——收益很小。
- 机理（重要）：剪枝只在**精搜**生效，而精搜候选是粗筛后 TOP-K 锚点的 ±1 邻域，
  本身都处在**高相关区域**，上界很难把它们剪掉；低分区域早在粗搜阶段就被筛掉，轮不到剪枝。
  即：**当前两级结构里，剪枝缺少可剪的"明显不匹配"样本**，收益天然有限。

----------------------------------------------------------------
## 4. 结论

**两种手段均不采纳**（M1 范围内不改生产匹配器）：

1. 3×3 采样：×1.39（组合后 ×1.70）收益有限，且引入 best 位置漂移（7/51 帧），不满足
   「判定语义逐字段不变」的既有口径；
2. 部分和剪枝：语义零漂移，但 ×1.06 的收益与实现复杂度（上界推导、后缀数组、每 4 行检查）
   不成比例；
3. 即便按最乐观的组合（×1.70）推算，真机 P95 也只能从 ≈313ms 降到 ≈184ms，
   **距 NFR-01 的 20ms 仍差约 9 倍**——不是"再抠一点算法"能解决的量级差。

对 A9 的判定：**M1 内 A9 不勾选，如实记录**（T1-10 任务卡已注明 NFR-01 / NFR-02 最终验收在 M5）。

## 5. 结构性建议（留后续里程碑，按性价比排序）

真正的成本量级 = **窗口面积 × 模板像素 × 信号数**。当前 launch_start 窗口为「选区各向外扩一个选区尺寸」
（约 3×3 选区面积），多信号时成本近似线性叠加（设备侧已有 7 信号）。可选方向：

1. **按状态启用信号子集**：只匹配「当前状态下可能转移到的少数状态」的信号（与"动作锚点按状态启用"
   同思路），可把多信号成本降到常数级；代价是需要状态机提供候选集，且首次进入仍需全扫。
2. **收紧搜索窗口**：把标定窗口由「外扩 1 个选区尺寸」改为更紧的外扩（如 0.5 倍），
   窗口面积随之外扩系数平方下降；代价是标志位移容忍度降低（需重新标定与回归）。
3. **多尺度 / 帧降采样粗定位**：在 1/2 或 1/4 尺度上先粗定位，再回原尺度局部精搜——
   粗搜成本按面积 1/4～1/16 下降（本质是把采样放到空间域而非模板域）。
4. **匹配算法替换**：如基于二值特征（Census / ORB 式描述子）或 FFT 相关；改动大、需重新验证
   遮罩 / 动态背景容忍度（A7 指标复跑）。
5. **需求口径确认**：若上述均不可行，需就 NFR-01（<20ms）与需求方确认是否放宽、或改为
   "在稳定档 3s 间隔下不影响体验"的等效口径。

建议：将 1 / 3 登记为后续里程碑的性能任务（需先在真机确认多信号下的实际 P95，作为新基线）。
