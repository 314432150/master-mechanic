# 识别证据仓

> 存放 §5「识别能力要求」的全部证据：样本索引、指标报告、标定说明、研究任务结论。
> 每份报告必须可复现（同数据 + 同参数 → 同结果）。

## 规则

1. **样本集版本化**：同一批画面数据给固定名称（如 `set-YYYYMMDD-NN`）；采集设备与场景在索引中注明。
2. **报告必含**：样本量 n、日期、参数集版本、三类干扰（半透明遮罩 / 动背景 / 相似目标）**分别统计**；误报按上界公式表述。
3. **可复现**：参数调整后必须对既有样本整体重跑，并出比对报告。
4. **设备无关**：标定永远在目标设备上执行；报告中的设备参数不得成为代码常量。
5. **研究任务结论**（R-1 / R-2 等）也归档于此：结论 + 截图证据 + 反例。

## 目录约定（按需创建）

| 名称 | 内容 |
| --- | --- |
| `samples-index.md` | 样本集索引：版本、来源设备、场景、样本量 |
| `reports/` | 指标报告：`report-YYYYMMDD-主题.md` |
| `research/` | 研究任务结论：`research-<主题>.md` |
