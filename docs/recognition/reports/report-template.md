# 指标报告模板（T1-6d）

> 用途：回放指标报告的结构定义（模板先于样本收集，§5 验收口径）。
> 实例报告由 JVM 回放工具（测试源集 `ReplayTool`）生成至本目录，命名 `report-YYYYMMDD-主题.md`。
> 渲染器 `ReplayReportRenderer` 与下列节标题、字段一一对应；改动本模板必须同步渲染器与其单测
> （`ReplayReportRendererTest` 校验模板—渲染一致性）。
>
> 样本集目录 = `manifest.txt` 清单 + 画面文件（同目录）；清单格式见 `ReplaySetCodec`。

以下为实例报告骨架（示例值为占位示意）。

---

# 回放指标报告：<主题>

- 样本集：set-YYYYMMDD-NN
- 采集设备：<设备>
- 采集场景：<场景>
- 报告日期：YYYY-MM-DD
- 参数集版本：<paramsKey>（命中线 x / 差距线 y / 峰值间距 z）
- 运行次数：N（≥ 2）

## 口径与公式

固定文本（逐字输出）：

- 误报定义：负样本上出现任一信号命中（MATCHED）即为该样本误报；不可信（UNRELIABLE）按未识别处理，不计误报。
- 零误报上界：n 个样本 0 次误报 → 真实误报率上界 = 1 − 0.05^(1/n)（95% 置信）。
- 负样本总量下限 60；不足时不得声称「零误报」。
- 三类干扰分别统计，不得合并成一个总通过率。

## 样本量

- 负样本合计：N（达到口径下限 ≥ 60；不足时输出「样本不足：低于口径下限 60，不得声称「零误报」」）
- 正样本合计：M

## 三类干扰分列（不得合并）

固定四行（三类干扰 + 普通负样本；未采集的类别以 n = 0 行显式呈现，覆盖缺口不得隐藏）。
单元格规则：n = 0 → 未采集；有误报 → 点估计（x/n）；零误报 → 上界 1 − 0.05^(1/n) 数值。

| 类别 | 样本量 n | 误报数 | 点估计 / 上界 |
| --- | --- | --- | --- |
| 半透明遮罩（干扰①） | 20 | 0 | 上界 0.139108 |
| 动背景（干扰②） | 20 | 0 | 上界 0.139108 |
| 相似多目标（干扰③） | 20 | 0 | 上界 0.139108 |
| 普通负样本 | 0 | — | 未采集 |
| 合计（仅供样本量核对，不作为总通过率结论） | 60 | 0 | — |

## 正样本（参照）

- 命中 x / M（目标信号命中且位置偏差在工具容忍范围内）；未采集时注明「未采集正样本。」。

## 可复现比对

- 运行次数：N
- 逐字段比对：无差异 → 「逐字段一致（无差异）」；有差异 → 列明条数与逐条明细（样本 + 信号 + 字段 + 基准 / 实际）。

命令行原文（工具读样本集目录 → 跑识别 → 生成报告）：

