# 术语表

> 用途：固定本仓库的关键词，AI 与文档不得另造近义词。新术语先加到这里，再在别处使用。
> 「出处」列指向 `requirements.md` 章节，便于回溯口径。

## 界面与状态

| 术语 | 定义 | 出处 |
| --- | --- | --- |
| 状态 | 程序对当前界面的判定结果，取值仅限：启动页、服务器列表、大厅、农场、好友列表、好友的农场、活动弹窗、未知 | §2.1 |
| 界面标志（标志） | 页面上可被辨认的稳定视觉元素；识别以"界面上是否存在该标志"为单位 | §2.1 |
| 动作锚点（操作目标） | 流程步骤或异常处理中需要被点击的界面元素在标定产物中的记录；与「界面标志」并列的独立角色，只回答"点哪里"，不参与状态判定 | §2.1、FR-01、FR-04 |
| 命中 / 未命中 | 某画面中存在 / 不存在某标志的判定结果 | §2.1 |
| 滞回 | 状态切换不信任单次识别：进入需连续 2 次命中，离开需连续 3 次未命中 | §2.2 |
| 未知（状态） | 连续 3 次未命中任何标志的判定结果 | §2.2 |
| 入口标志 | 常驻守护**待命期**用于判断"是否该进入弹窗检查"的界面标志；当前 = 启动页 ∪ 活动弹窗（命中任一即进入弹窗期）。仅在流程未启动时起作用，流程运行中改用各步骤的预期集合 | FR-01 |
| 状态标签 | ~~悬浮窗中**只负责显示**的部件（当前状态 / 当前动作）~~ —— **已于 2026-09-17 取消**（用户口径；动作反馈改由「浮窗提示」承接） | FR-07 |
| 手柄 | 悬浮窗中承担**交互**的紧凑部件（单击展开菜单；**固定贴右缘、不可拖动**，2026-09-14 起） | FR-07 |
| 服务器清单 | 用户维护的服务器条目列表（区服名称 + 备注 / 角色名 + 等级）；换号时按**名称**定位，备注与等级只用于辨识，不参与定位 | FR-07 |

## 识别

| 术语 | 定义 | 出处 |
| --- | --- | --- |
| 判定记录 | 一次识别的完整结论：命中了哪个标志、位置、置信度、同画面最强竞争位置 | §5-1 |
| 不可信 | 存在多处高分、或最高分与次高分差距过小；此时按未识别处理 | §5-2 |
| 误报 / 漏报 | 误报 = 把非目标判为目标；漏报 = 目标存在却未命中 | §5 |
| 负样本 | 不含目标的画面样本；验收误报率时不得少于 60 个 | §5 |
| 误报率上界 | n 个样本 0 次误报时，真实误报率上界为 1 − 0.05^(1/n)；样本不足不得声称"零误报" | §5 |
| 回放样本集 | 固定的一批画面数据；同数据 + 同参数重复执行必须得到相同结果 | §5-4 |
| 标定 | 在目标设备上自行建立识别能力的过程；禁止使用开发设备参数 | §5-5 |

## 运行与操作

| 术语 | 定义 | 出处 |
| --- | --- | --- |
| 常驻守护 | 长期后台待命，仅自动处理 FR-01（活动弹窗）一类异常 | §1.2 |
| 跑号 | 切换区服、登录、拜访指定好友的 10 步主流程（**旧称「巡查」**）；**配置侧（FR-03）已于 2026-09-16 移除**，改由下面的「拜访预设」驱动 | §3.2 |
| 跑号项 | ~~一个「服务器清单里的区服 + 好友清单里的好友」的配置单位（旧称「巡查项」）~~ —— **已废止**（2026-09-16：跑号配置随 FR-03 整体移除） | FR-03 |
| 步骤验证 | 每步动作执行后确认画面已变为预期状态，通过才允许下一步 | FR-04 |
| 中止 | 停止当前流程并提示，不自动重试，等用户决定如何继续 | FR-04/05 |
| 暂停 | 游戏离开前台等原因临时停止动作，回前台后需用户确认才继续 | FR-05 |
| 演练模式（dry-run） | 只识别、不点击的运行方式，用于识别能力验收阶段 | 附录-推进顺序 |
| 点击审计 | 每次点击都能反查到对应的判定记录与判据 | FR-06、NFR-05 |
| 采集会话 | 画面采集的一次授权周期；"用户切到别的应用"不等于会话终止 | FR-09 |
| 前台判定 | 以独立信号判定目标应用是否位于前台；不得用"未识别到标志"代替 | FR-09 |
| 研究任务 | 产物为样本与结论文档（而非代码）的任务，用于解决 §7 待确认事项 | §7 |

## 一键拜访（2026-09-16 起，取代已移除的跑号配置）

| 术语 | 定义 | 出处 |
| --- | --- | --- |
| 拜访预设（界面名「拜访规则」） | 悬浮窗内可直接编辑的一份配置 = **服务器选择策略 + 好友**；菜单一级点一次即执行整条流程；落盘 `files/preset/visit.txt`（`mm-visit-preset` v1） | FR-07 |
| 顺序轮换 | 服务器选择策略之一：**按服务器清单顺序换下一个**（日常路径）；另一策略是"指定某区服"。界面用词，**不再叫「自动切换」**（2026-09-19 用户口径） | FR-07 |
| 换号拜访 | 菜单一级项：**换号 + 拜访**整条走完；未配置时显示「换号拜访（未配置）」 | FR-07 |
| 只拜访 | 菜单一级项：**跳过换号**，在当前区服直接去见预设好友；未配置时显示「只拜访（未配置好友）」 | FR-07 |
| 浮窗提示 | 动作**成功发出**后在**屏幕底部**浮出的短提示（≈2 秒，如「换号拜访：星月晚」）；替代已取消的状态标签 | FR-07 |
