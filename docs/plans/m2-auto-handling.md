## 任务卡（草案）

### T2-1 预期集合驱动落地（识别层口径切换）

- 目标：`ActiveSignalSelector.select(state, round)` → `select(expected)`；空集合 = 不搜；「未知」= 预期集合内连续 3 次未命中
- 验收：M1 演练路径改为显式声明全集后行为不变（固定批次 `set-20260912-03` 判定零漂移）；单测覆盖「空集合 / 子集 / 全集」三态
- 证据：单测 + 固定批次回放报告
- 备注：预期集合的需求依据为 FR-04「进入下一步的验证」列（步 1 = {农场, 好友的农场, 大厅}；步 6 = {大厅} ∪ {活动弹窗}）

### T2-2 FR-01 / FR-02 标定补充（T1-8b 并入，前置）

- 目标：标定 `popup_close` 多样式 +「关闭 / 跳过」文字标志、新手引导标志、新手大厅标志
- 验收：逐信号真机复演命中；产物同源灰度裁剪（红线 4）
- 证据：产物 + 复演日志（`docs/verification/`）
- 捷径：停在新手引导弹窗（未标定界面）会走未知态全扫 → 约 90 秒补齐全部信号窗口

### T2-3 动作锚点角色字段 + 点击转发层

- 目标：产物 v2 角色字段（标志 / 锚点；同一元素两种角色须为两条独立记录）、按当前状态启用、标定页支持该类型；点击转发层强制 ≥ 300ms
- 验收：单测（角色解析 / 按状态启用 / 间隔节流）+ 真机一次真实点击核对（用户执行）
- 证据：单测 + 真机日志与截图
