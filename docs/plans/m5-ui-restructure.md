## 1. 目标结构（确认后即按此实现）

```
底部导航（一级，4 项）
├─ 运行      现在能不能跑 / 跑到哪了 → 发起「换号 / 拜访 / 换号+拜访」→ 停止 / 继续
├─ 规则      拜访规则：区服策略（「下一个」/ 固定区服）+ 好友 → 执行
├─ 清单      Tab：区服清单 ｜ 好友清单（增删改 / 排序 / 改名同步）
└─ 标定      样本帧 + 产物与参数 → 全屏「标定工作台」

抽屉（系统级，4 项）
├─ 授权与权限  四项状态与一键授予（**首次启动缺授权时自动进这里**）
├─ 诊断        画面在不在来 / 当前识别画面与分数 / 单帧耗时 / 日志
├─ 设置        自动关弹窗暂停·恢复 / 悬浮窗提示位置重置 / 退出 App
└─ 帮助·关于   术语与流程说明（长文案里"为什么"的归宿）
```

**组件映射**（用户要求"把安卓结构组件用上"）：

| 用途 | 组件 |
| --- | --- |
| 页面切换与返回栈 | Navigation Compose（`NavHost`） |
| 骨架 / 一级导航 / 系统级入口 | `Scaffold` + `TopAppBar` / `NavigationBar` / `ModalNavigationDrawer` |
| 清单两个 Tab | `SecondaryTabRow` |
| 行内操作与"说明" | `ModalBottomSheet`（取代现在一屏的 `AlertDialog`） |
| 长说明 | 折叠区（默认收起），首屏永远 1 行 |
| 撤销回执 | 沿用现有 `SnackbarHost` |
