## 范围边界

- **做**：授权状态采集与引导、前台独立判定、后台常驻服务与通知、悬浮窗壳（仅前台可见、触摸穿透、紧凑、收起态手柄）。
- **不做**：画面识别、任何点击（本里程碑全程零点击）、巡查逻辑、悬浮窗完整交互（拖动 / 贴边 / 菜单，M3 再做）。

## 验收清单（全部需真机核对）

- [ ] A1 关键授权各自有明确状态展示；缺失时给出可操作提示，无静默失败（FR-08）
- [ ] A2 前台判定为独立信号；目标应用前后台切换后 2 秒内生效；判定不可用时按"非前台"处理（FR-09）
- [ ] A3 服务常驻运行，系统通知可见；切后台 / 熄屏不被中止（FR-08）
- [ ] A4 悬浮窗仅在目标应用前台时可见；非前台完全消失（不占触摸）；回前台以收起态恢复（FR-07）
- [ ] A5 悬浮窗触摸穿透，覆盖区域内游戏操作不受影响；尺寸紧凑只包内容（FR-07）
