## 范围边界

- **做**：采集层（采集会话生命周期）、识别层（标志检测与判定记录）、决策层（状态机滞回）、标定、回放与指标工具、演练模式（只识别、不点击）、悬浮窗状态文字随识别更新。

### T1-5 标定

- 目标：在目标设备上自建识别能力（样本采集 → 参数建立 → 落盘），全程无开发设备参数
- 验收：A6
- 证据：标定流程真机记录 + 产物审查（零设备绑定）
- 实现切片：
  - T1-5a 产物模型与编解码（纯逻辑）：产物 = 信号（模板 + 搜索窗口）+ 状态映射 + 匹配参数 + 标定帧尺寸；文本格式编解码；模板提取复用运行时同源灰度路径
  - T1-5b 标定采集与标注（应用侧）：从采集会话录制帧样本（落盘）；应用内挑帧、框选、命名、设参、保存产物；采集会话建立时加载产物接入识别循环
  - T1-5c 真机标定与核对：在目标设备完成真实界面标志标定（弹窗 / 新手等不可控界面留待后续补充），核对真实标志驱动的状态变化（补 T1-4 备注事项）
  - T1-5d 标注交互增强（真机标定反馈）：帧预览支持双指缩放 / 平移（横屏内容在竖屏帧画布中过小，需放大后框选）；选框支持拖动框内整体移动、拖动边 / 角拉伸（图片工具交互）；框编辑与视图变换为纯运算并单测覆盖，选框比例坐标语义不变（零设备绑定不破）
  - T1-5e 标注交互第二轮（真机标定反馈）：归属状态绑定默认信号名（选中状态自动填入名称框，免手输）；「新手大厅 / 新手引导」拆分为两个独立状态（§2.1 与术语表同步）；框选改为全屏画布（弹出式操作，「完成」退出返回，放大后不再遮挡页内其他区域）；选框左上角拉伸锚点改为关闭按钮（点按清除当前选框、可立即重新框选）；关闭命中为纯运算并单测覆盖，选框比例坐标语义不变（零设备绑定不破）
  - T1-5f 标定页布局聚焦（真机标定反馈）：缩略图列表由大图条改为矮方块条（裁切预览）、「框选标志」操作说明移入点击 ⓘ 弹窗展示、预览大图限制最大高度——预览大图与缩略图列表同屏可见，挑帧无需来回滚动
  - T1-5g 信号名录入移除（真机标定反馈）：信号名完全由归属状态的默认名决定，标定页不再展示名称输入框（使用者无需关心命名）
  - T1-5h 预览交互增强（真机标定反馈）：预览图支持左右滑动切换样本帧（缩略图列表选中随动）；双击预览图进入全屏框选；移除「全屏框选」按钮，改为预览画布内正下方的全屏图标（深色衬底 + 白色图标，与画面背景保持对比）
  - T1-5i 预览切换防闪烁（真机标定反馈）：预览画布按最近解码帧比例预留高度（≤260dp），切换样本帧时布局不塌缩；加载 / 失败态在占位画布内展示
  - T1-5j 缩略图联动时差修正（真机标定反馈）：滑页与缩略图联动由「定格后同步」改为「过半即同步」——拖动过半缩略图高亮立即随动，松手回弹不触发
- 备注：标定口径与 T1-1 的 ADR-003 衔接；样本索引归入 `docs/recognition/`

### T1-6 回放与指标工具

- 目标：回放样本集管理、同数据重跑比对、误报率统计（负样本 ≥60、三类干扰分列、上界公式）
- 验收：A7
- 证据：指标报告（含样本量 n 与上界）
- 实现切片：
  - T1-6a 样本集结构与加载（纯逻辑）：固定批次样本集 = 清单（样本文件名、类别标签〔正样本 / 负样本，负样本含三类干扰分列：半透明遮罩 / 动背景 / 相似多目标〕、正样本目标标志与位置、备注）+ 画面文件；清单解析与样本模型纯逻辑并单测覆盖；格式遵循 `docs/recognition/README.md` 版本化约定（set-YYYYMMDD-NN）
  - T1-6b 误报指标计算（纯逻辑）：按类别分列统计（样本量 n / 误报数 / 点估计）；「零误报」仅以上界 `1 − 0.05^(1/n)` 表述，n < 60 时输出「样本不足、不得声明零误报」标记；三类干扰不得合并统计；单测覆盖 0 误报 / 有误报 / n=60 边界 / 样本不足
  - T1-6c 同数据重跑比对（纯逻辑）：同一数据集 + 同一套参数多次运行 → 判定记录逐字段比对（沿用 T1-3 口径，扩展至真实样本集与参数版本）；差异明细定位到「样本 + 字段」；单测覆盖
  - T1-6d 指标报告模板与渲染（模板先于样本收集）：`docs/recognition/reports/report-template.md` 定义结构（口径与公式 / 样本量 / 参数集版本 / 三类分列 / 可复现命令）；渲染器与模板字段一致（纯逻辑 + 单测）；JVM 回放工具的 IO 适配（读样本、生成报告至 `docs/recognition/reports/`）由测试源集承载
  - T1-6e 固定批次采集与首份指标报告（A7 证据）：真机采集固定批次（含三类干扰与 ≥60 负样本）→ 清单标注 → JVM 回放生成首份报告；样本索引同步 `docs/recognition/samples-index.md`
  - T1-6e 备注（2026-09-12 会话方向复核，替代此前「横持重标定」前置）：画布方向由建会话瞬间的系统显示方向决定——日常配置（旋转锁定竖屏 + 辅助 App 竖屏前台）建会话 → 竖画布 1440×3168；游戏前台时游戏自声明横屏（应用请求优先于用户锁定），横屏内容旋转嵌入画布即真实使用形态；物理持机姿态不进入该链路。采集与运行保持同一建会话条件即可，无需横持重标定。
- 备注：回放样本集为固定一批（§5-4）；指标报告模板先于样本收集定义

### T1-9 性能基线（A9）

- 目标：单帧处理耗时 < 20ms（P95，连续 100 帧）可测量、可取证；检测间隔自适应（变化中 0.5 ~ 1s，稳定时 3 ~ 5s）真机核对
- 现状前提：节流两档已落地（ACTIVE 1000ms / STABLE 3000ms，均落在需求区间内），稳定度切换逻辑已接线（T1-4）；缺「单帧处理耗时」测量手段与取证口径
- 验收：A9
- 证据：真机演练日志——连续 ≥100 帧的「单帧处理耗时」统计输出（P95 < 20ms）+ 节流档切换记录（变化 / 稳定两场景对照）+ 帧管线统计节奏，归档 `docs/verification/`
- 实现切片：
  - T1-9a 耗时统计器（纯逻辑）：逐帧记录处理耗时，连续 100 帧为一窗（满窗输出 P95 / 平均 / 最大并重置）；P95 取 nearest-rank（第 ⌈0.95n⌉ 位）；单测覆盖窗口边界 / P95 取值 / 满窗重置
  - T1-9b 帧管线接入与日志：`processFrame` 内测量「灰度转换 + 识别循环（含滞回）」耗时（转换失败轮不计入样本）；满窗输出一行统计日志；节流目标档位实际变化时输出切换日志（含前后间隔与判据），供 A9 间隔证据直接取读
  - T1-9c 真机核对（A9 证据）：演练模式下长跑，覆盖「稳定（无状态变化）」与「变化（状态转移前后）」两场景，收集 P95 统计输出与档位切换日志
- 备注：NFR-01 / NFR-02 最终验收在 M5（本卡只交 M1 基线：测量手段 + 首轮真机数据）；间隔参数不调整（1000ms ∈ 0.5~1s、3000ms ∈ 3~5s）；耗时口径不含节流判定、标定旁路与统计日志本身

### T1-10 性能达标优化（A9 整改）

- 目标：单帧处理耗时 P95 < 20ms（真机连续 100 帧统计）；判定语义不变（固定批次新旧判定记录回归通过）
- 背景：T1-9 首轮真机数据 P95 2287.6ms（灰度 52.7ms / 识别 2241.2ms）——瓶颈为朴素 NCC 全窗滑动（约 9.6e7 次乘加 / 帧）；桌面同源探针 45ms（超标 2.25 倍，设备环境再放大约 50x）
- 验收：A9（达标）
- 证据：优化前后真机 100 帧统计对照 + 固定批次回归（判定记录逐字段比对 + A7 指标复跑）+ 单测
- 实现切片：
  - T1-10a 匹配算法优化（纯逻辑）：帧侧搜索窗口前缀和（整数积分图，位置统计量零误差）+ 采样粗搜（模板 2×2 抽取，网格步进）+ 候选网格点全精度精搜（精确覆盖网格间隙）；最终候选分数全部取全精度（阈值与差距判定输入不变）；单测覆盖「粗搜 + 精搜与穷举全精度一致」「边界」「确定性」
  - T1-10b 帧管线裁剪与调度（平台层）：灰度仅转换「各信号窗口行并集」（原始帧拷贝量按行裁剪，灰度数组全帧尺寸、窗口外留零）；帧线程处理时提升至显示优先级
  - T1-10c 离线回归与提速取证（JVM）：固定批次「优化前 / 后」判定记录逐帧比对 + 加速比探针（桌面对照）+ A7 指标复跑（三次一致性）
