## 范围边界

- **做**：采集层（采集会话生命周期）、识别层（标志检测与判定记录）、决策层（状态机滞回）、标定、回放与指标工具、演练模式（只识别、不点击）、悬浮窗状态文字随识别更新。
- **不做**：任何点击（本里程碑仍全程零点击）；FR-01 / FR-02 的动作下发（M2）；巡查（M4）；悬浮窗完整交互（M3）。

## 验收清单（全部需真机核对）

- [x] A1 采集会话生命周期完整：建立 / 维持 / 终止均可见且正确；切换其他应用不终止会话，会话本身终止才停止循环（FR-09 会话区分）
- [x] A2 识别层可复现：同一批画面数据 + 同一套参数重复执行，结果完全一致（§5-4）
- [x] A3 判定记录完整：命中的标志、位置、置信度、同画面最强竞争位置四项齐全（§5-1）
- [x] A4 不可信处理：多处高分、或最高分与次高分差距过小时，按未识别处理（§5-2）
- [x] A5 状态机滞回：进入连续 2 次命中、离开连续 3 次未命中、连续 3 次未命中任何标志 → 未知；非前台期间不消耗连续计数（§2.2、FR-09）
- [x] A6 设备自标定：识别能力在目标设备上建立，代码零设备绑定参数；更换设备可重建（§5-5）
- [ ] A7 误报率口径达标：负样本 ≥60；三类干扰分别统计；结论以上界公式表述（§5）
- [ ] A8 演练模式：只识别不点击地运行；悬浮窗文字随识别状态更新
- [ ] A9 性能基线：单帧处理 < 20ms（P95，连续 100 帧）；检测间隔自适应（变化中 0.5 ~ 1s，稳定时 3 ~ 5s）（NFR-01、NFR-02 的 M1 基线，最终验收在 M5）

## 任务卡

### T1-1 决策前置：落地 ADR-003（识别技术路线）

- 目标：确定标志检测技术途径，覆盖 §5 全部要求（判定记录产出、不可信处理、设备自标定衔接）
- 验收：ADR-003 状态为「接受」；`architecture.md` 开放决策表同步
- 证据：ADR 文件链接
- 备注：先于 T1-3；识别层保持「纯逻辑、可离线回放」的分层约束

### T1-2 采集层：采集会话

- 目标：采集会话的创建、维持与终止，向识别循环供给帧数据
- 验收：A1
- 证据：真机会话生命周期记录（日志 + 界面状态）
- 备注：M0-T0-4 顺延项；「切走不终止、会话终止才停」按 FR-09 区分；采集期间保持零点击

### T1-3 识别引擎（纯逻辑）

- 目标：标志检测 → 判定记录（命中、位置、置信度、竞争位置）→ 可信性判定；输入帧数据，输出判定
- 验收：A2、A3、A4
- 证据：JVM 单测 + 回放比对报告
- 备注：不含任何设备绑定常量（§5-5）；不依赖安卓框架，可在 JVM 离线重跑

### T1-4 状态机（滞回）

- 目标：§2.1 全状态 + §2.2 滞回 + 非前台冻结计数；识别循环接入采集帧管线（帧 → 判定 → 状态机 → 日志）
- 验收：A5
- 证据：滞回时序单测 + 真机状态变化日志（识别循环运行与冻结核对记录）
- 备注：状态变化必须输出日志（判定审计的一部分）；未命中任何标志达到阈值 → 未知；未知不操作；识别循环接入为 T1-2 帧管线既定承诺，NFR-02 自适应节流初版随接入落地（变化 / 稳定两档）；真实标志驱动的状态切换真机观察依赖标定产物（T1-5），届时补充核对

### T1-5 标定

- 目标：在目标设备上自建识别能力（样本采集 → 参数建立 → 落盘），全程无开发设备参数
- 验收：A6
- 证据：标定流程真机记录 + 产物审查（零设备绑定）
- 实现切片：
  - T1-5a 产物模型与编解码（纯逻辑）：产物 = 信号（模板 + 搜索窗口）+ 状态映射 + 匹配参数 + 标定帧尺寸；文本格式编解码；模板提取复用运行时同源灰度路径
  - T1-5b 标定采集与标注（应用侧）：从采集会话录制帧样本（落盘）；应用内挑帧、框选、命名、设参、保存产物；采集会话建立时加载产物接入识别循环
  - T1-5c 真机标定与核对：在目标设备完成真实界面标志标定（弹窗 / 新手等不可控界面留待后续补充），核对真实标志驱动的状态变化（补 T1-4 备注事项）
  - T1-5d 标注交互增强（真机标定反馈）：帧预览支持双指缩放 / 平移（横屏内容在竖屏帧画布中过小，需放大后框选）；选框支持拖动框内整体移动、拖动边 / 角拉伸（图片工具交互）；框编辑与视图变换为纯运算并单测覆盖，选框比例坐标语义不变（零设备绑定不破）
  - T1-5e 标注交互第二轮（真机标定反馈）：归属状态绑定默认信号名（选中状态自动填入名称框，免手输）；「新手大厅 / 新手引导」拆分为两个独立状态（§2.1 与术语表同步）；框选改为全屏画布（弹出式操作，「完成」退出返回，放大后不再遮挡页内其他区域）；选框左上角拉伸锚点改为关闭按钮（点按清除当前选框、可立即重新框选）；关闭命中为纯运算并单测覆盖，选框比例坐标语义不变（零设备绑定不破）
  - T1-5f 标定页布局聚焦（真机标定反馈）：缩略图列表由大图条改为矮方块条（裁切预览）、「框选标志」操作说明移入点击 ⓘ 弹窗展示、预览大图限制最大高度——预览大图与缩略图列表同屏可见，挑帧无需来回滚动
  - T1-5g 信号名录入移除（真机标定反馈）：信号名完全由归属状态的默认名决定，标定页不再展示名称输入框（使用者无需关心命名）
  - T1-5h 预览交互增强（真机标定反馈）：预览图支持左右滑动切换样本帧（缩略图列表选中随动）；双击预览图进入全屏框选；移除「全屏框选」按钮，改为预览画布内正下方的全屏图标（深色衬底 + 白色图标，与画面背景保持对比）
  - T1-5i 预览切换防闪烁（真机标定反馈）：预览画布按最近解码帧比例预留高度（≤260dp），切换样本帧时布局不塌缩；加载 / 失败态在占位画布内展示
  - T1-5j 缩略图联动时差修正（真机标定反馈）：滑页与缩略图联动由「定格后同步」改为「过半即同步」——拖动过半缩略图高亮立即随动，松手回弹不触发
- 备注：标定口径与 T1-1 的 ADR-003 衔接；样本索引归入 `docs/recognition/`
