二、验收对照（任务卡 T1-5l ①–⑥）
----------------------------------------------------------------

① 框选 + 选归属状态即落盘（同名覆盖、无中间步骤）
   实现：工作台点归属状态 chip → writeSignalFromSelection() 立即 upsert + CalibrationStore.save；
        全库无「提取为模板 / 保存产物」二次确认，无进程内草稿（CalibrationDraft 已删除）
   单测：upsertCreatesArtifactFromNothing / upsertReplacesSameNameEntirely /
        upsertReassignsStateOfSameName / upsertGroupsRulesByFirstAppearanceOrder

② 删除单条信号后产物立即更新，删空则产物文件删除（回到「无产物」）
   实现：CalibrationSignals.remove() 返回 null → CalibrationStore.delete()；否则立即覆盖写回
   单测：removeDropsSignalAndItsRule / removeLastSignalReturnsNull / removeMissingNameIsIdempotent

③ 产物信号可查看（模板灰度图 + 尺寸 + 窗口帧像素）并可删除
   实现：产物清单逐条列出「名称 → 状态 / 模板 WxH / 窗口帧像素」；
        TemplateDetailDialog 展示模板灰度图（CalibrationFrames.templateBitmap）+ 尺寸 + 窗口
        （SearchWindow.pixelBounds，floor/ceil 确定性换算）；单条删除 + 整体删除
   单测：windowAlwaysCoversSelectionInPixels（窗口覆盖选区）/ windowExpandsBySelectionSizeAndClampsToFrame

④ 无锚点后选框边缘与角完全无遮挡，命中区仅「框内移动 / 框外新建 / 左上关闭」三类
   实现：FrameEdit 删除 FrameHandle / resize / outerFrame / handleCenters，绘制层删除手柄与外层框，
        只保留红色真实选框 + 左上角外置关闭钮（外扩 16dp、半径 8dp、热区 20dp）
   单测：hitTestNearEdgesIsInside / hitTestOnSelectionBorderIsOutside / hitTestOutsideRegionIsOutside /
        closeButtonCenterSitsOutsideSelectionCorner / closeButtonCenterClampsToFrameBounds /
        hitCloseButtonHitsAtExternalCenter / hitCloseButtonRequiresBothAxes /
        hitCloseButtonNeverFiresInsideSelection / zoomAllowsPixelLevelAlignment（MAX_SCALE 16×）

⑤ 几何不一致的写入被拒绝且提示明确
   实现：写入前 CalibrationSignals.geometryError() 校验标注帧几何与产物记录几何；
        不一致直接返回提示「画布几何不一致：本次帧 AxB，产物 CxD。请先删除产物后重标，
        或在与产物相同方向的画布下建会话。」（不写盘）
   单测：geometryErrorIsNullWithoutArtifactOrWhenEqual / geometryErrorReportsMismatch /
        upsertRejectsGeometryMismatch

⑥ 零设备绑定不破（模板 / 窗口 / 参数仍全部来自产物）
   实现：模板 = 标注帧原分辨率裁剪（TemplateExtractor）；窗口 = 选区比例外扩一倍（SelectionWindow）；
        参数 = 产物级文本编辑（CalibrationSignals.parseParams）；工作台无任何设备相关常量
   单测：parseParamsAcceptsValidAndRejectsInvalid / defaultParamsMatchDefaultTexts /
        FrameEditTest 全部（比例坐标、与帧分辨率解耦）
