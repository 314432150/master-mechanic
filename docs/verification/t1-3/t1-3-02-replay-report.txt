M1-T1-3 回放比对报告（验收 A2：同一批画面数据 + 同一套参数 → 结果完全一致，§5-4）

比对对象：识别引擎（SignalDetector + TemplateMatcher）输出的判定记录。
样本集：固定种子合成画面（SyntheticImages 程序化生成；种子固定 → 每张画面数据恒定，
  测试代码即样本定义，无外部文件依赖）。

本批次定义（SignalDetectorTest.replayOfSameInputProducesIdenticalRecords）：
- 画面 400x300：底噪 + 两个目标纹理
    · 标志A 纹理 20x16 @ (30,40)，全屏搜索窗口
    · 标志B 纹理 24x18 @ (260,200)，搜索窗口为右下 1/4（比例窗口）
- 参数：命中线 0.85 / 差距线 0.1 / 峰值间距 5（测试参数）

比对方法：
同一画面 + 同一参数，连续执行 detect() 三次；判定记录逐字段比较
（信号名 / 结论 / 最高分位置与分数 / 竞争位置与分数）。

结果：
- 三次输出逐字段一致（断言通过）；
- 两条信号结论均为 MATCHED 且位置正确（标志A (30,40)、标志B (260,200)）。

确定性来源（引擎设计约束，§5-4）：
- 纯数值计算、无随机源；单线程固定遍历顺序；
- 峰值排序含确定性 tie-break（同分按 y、x 升序）；
- 窗口换算用 floor/ceil（无浮点歧义的边界语义）。

  标定样本采集属 T1-5、回放与指标工具属 T1-6；
- 该扩展将直接复用本引擎与参数对象，比对逻辑（同数据重跑 → 逐字段比）不变。
