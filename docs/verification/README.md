## M0-T0-3 前台判定核对记录（2026-09-11）

- 设备：vivo V2463A / Android 16（API 36）/ 1440×3168
- 目标应用：《王者荣耀》国服（`com.tencent.tmgp.sgame`，设备实装）；原始日志：[t0-3-01-timeline-log.txt](t0-3/t0-3-01-timeline-log.txt)（含操作标记 MM-Marker，与状态日志同一时间源，可直接相邻对比）

| 场景 | 操作发出 | 判定生效 | 延迟 |
| --- | --- | --- | --- |
| 切后台（HOME） | 20:05:55.667 | 20:05:56.010 | **343ms** |
| 热态切到其他应用 | 20:06:21.865 | 20:06:22.313 | **448ms** |
| 热态切回游戏 | 20:06:26.077 | 20:06:27.692 | **1.615s** |
| 熄屏 | 20:07:11.759 | 20:07:12.731 | **972ms** |

- 结论（验收 A2）：
  - 独立信号：判定仅依据无障碍服务的活动窗口包名，与画面识别无任何耦合；
  - 2 秒内生效：实测切换延迟 343ms–1.6s，全部达标；
  - 判定失败即非前台：服务未连接 / 查询失败 / 服务销毁 → 输出「非前台」（JVM 单测覆盖查询失败分支；真机关闭服务期间零误报、零残留信号）。
- 补充说明：
  - 实现为双来源：窗口事件为主（上述延迟均为事件链路），1.5s 周期主动复核兜底防丢事件；
  - 游戏冷恢复期间（如发起于 20:05:58、生效于 20:06:05 的 6.9s 案例）目标应用确实尚未取得焦点——判定「非前台」是正确行为；焦点一取得立即切换（窗口事件驱动）；
  - 锁屏（NotificationShade）保持「非前台」；解锁回游戏即时恢复「前台」；
  - 服务关闭→重开（vivo 界面流程，关闭确认 + 7s 防误触倒计时）：关闭期间无任何 FOREGROUND 误报，重开后恢复正常；
  - 环境事实：王者荣耀绑定登录页由游戏应用自身绘制（非跨应用界面），与 ADR-001 单应用采集口径吻合；设备存在「主应用 / Ⅱ·分身」双实例，冷启动会触发 vivo 实例选择器（选择器界面判定为非前台，正确）。后续真机测试遇实例选择器时，统一选择主应用（「王者荣耀」）继续测试。
