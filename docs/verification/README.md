- 补充验证：
  - 会话制：强杀进程重开后屏幕采集回到「未授权」（[t0-2-04-session-reset.png](t0-2/t0-2-04-session-reset.png)），符合 ADR-001；
  - 自动刷新：从系统设置页返回（onResume）后状态即时刷新，无需手动操作；
  - 边界发现：vivo 在应用被「强行停止」后会撤销其无障碍授权——界面下次启动正确显示「未开启」并给出引导，符合 FR-08「不得静默失败」。
